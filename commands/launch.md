<![CDATA[# /launch Command

Generate a complete Product Hunt launch kit with all marketing assets.

## Usage

```
/launch                    # For current project
/launch "Product Name"     # With specific product name
/launch --platform ph      # Product Hunt (default)
/launch --platform all     # All platforms
```
